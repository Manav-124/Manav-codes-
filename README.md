# Engineering Systems Lab

A hands-on portfolio of embedded systems, hardware validation, automated testing, diagnostics, and IoT engineering.

This repository is organized like a small engineering lab rather than a collection of unrelated demos. Each project focuses on a different part of the hardware lifecycle: sensing, firmware, validation, production test, communications, fault diagnosis, and reporting.

> **Note:** The repository supports both physical hardware and simulation. Data generated by simulation is explicitly identified as simulated so results remain reproducible without lab equipment.

## Lab Projects

| # | Project | Focus | Main Technologies |
|---|---|---|---|
| 01 | Automated Hardware Validation Bench | Automated electrical tests and pass/fail reports | Python, PyVISA-style interfaces, CSV/JSON |
| 02 | STM32 Sensor Health Monitor | Embedded sensing and fault-state firmware | C, STM32, ADC, UART, state machines |
| 03 | Production Test Station | Serial-number based manufacturing test workflow | Python, SQLite, CLI, test sequencing |
| 04 | IoT Equipment Monitor | Telemetry, thresholds and equipment-health monitoring | Python, MQTT concepts, JSON |
| 05 | Signal & Fault Analyzer | Signal statistics and anomaly detection | Python, NumPy |
| 06 | Embedded Safety Controller | Multi-sensor safety logic and actuator control | C/C++, Arduino/STM32 concepts |

## Design Philosophy

The projects use a common pattern:

**Acquire → Validate → Diagnose → Record → Report**

That makes the repository useful for hardware test, validation, electronics technician, embedded systems, production test, systems integration, and junior hardware engineering roles.

## Getting Started

Most Python examples use only the standard library so they are easy to run.

```bash
git clone https://github.com/Manav-124/Manav-codes-.git
cd Manav-codes-
python3 projects/01-hardware-validation-bench/validation_bench.py
```

The embedded projects are written as portable reference firmware and can be adapted to STM32CubeIDE, Arduino IDE, PlatformIO, or another MCU toolchain.
